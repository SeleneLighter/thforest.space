Problem 31

编程验证当很小的时候计算, 用公式比直接用原公式精度更高. 这说明大小类似的两个浮点数的减法并不总是有害的，有些情况下如果能够有效利用反而是有益的, 称为良性相消 (benign cancellation).

Proof

import math

f1 = lambda x: math.log(1 + x) / x
f2 = lambda x: math.log(1 + x) / ((1 + x) - 1)

print(f"f1(1e-5) = {f1(1e-5)-1}\tf1(1e-10) = {f1(1e-10)-1}\tf1(1e-15) = {f1(1e-15)-1}")
print(f"f2(1e-5) = {f2(1e-5)-1}\tf2(1e-10) = {f2(1e-10)-1}\tf2(1e-15) = {f2(1e-15)-1}")
